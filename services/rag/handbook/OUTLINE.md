# Handbook outline (M2-08)

The fictional **CareFlow Demo Clinic** handbook that "Ask the clinic" (M2-09) answers from. It is
synthetic: no real hospital, person or insurer ("Insurer A/B/C"). It covers practical questions
only, never medical advice. Each section starts with `<!-- section: <id> -->`; the same id is used
in `en/` and `ar/`. The Arabic is written from the English (Western digits, ADR-032) and is not
validated by native speakers.
