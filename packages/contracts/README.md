# careflow-contracts

Source of truth for CareFlow schemas. Every lane imports these types from `careflow_contracts` and never redefines them (ADR-002, ADR-009).

- `schemas/`: JSON Schema 2020-12. `fact.schema.json` (provenance, source references, typed facts), `structured-facts.schema.json` (`StructuredFacts`, `FactKey`, `NeededFact`, `Turn`), `urgency-suggestion.schema.json`, `alert.schema.json`, `nurse-decision.schema.json`.
- `alert_templates.yaml`: the fixed, non-PHI alert line per rule (`en`, `ar`) and its `required_action` key.
- `src/careflow_contracts/generated/`: Pydantic v2 models, generated by `make contracts`. Never edit by hand; CI fails if they are stale.
- `src/careflow_contracts/validators.py`: cross-checks the models cannot express (provenance-source pairing, span offsets, unique fact ids, alert and suggestion evidence, override reasons).
- `fixtures/valid/` (personas: chest pain, stroke, drowsy child, sepsis with a partial NEWS2, routine) and `fixtures/invalid/`, named `<case>.<schema>.json`. Load them in any test with `careflow_contracts.testing.load_model`.

Safety rule 4: every fact carries a `provenance` (`EHR`, `PATIENT_STATED`, `DEVICE_MEASURED`, `NURSE_CONFIRMED`, `MODEL_INFERRED`) and a matching `source`.

Research prototype. Synthetic data only. Not for clinical use.
