- The 39 s are mostly prompt processing of the full `StructuredFacts` JSON Schema, which `structured()` puts in the system prompt.

## Deviations from the issue text

- **openai pinned to 2.54 (2.x), not 3.x**: openai 3.x uses the `httpx2` client, which respx cannot intercept, and the issue requires respx tests (ADR-013).
- `LocalTaskConfig.served_model` (default `default_model`): mlx_lm.server would try to load any other model name sent in a request.
- Thinking is disabled per request (`chat_template_kwargs`); `structured()` merges its instruction into the caller's system message (Qwen's template allows only one).
- Codex is read through `--output-last-message` (codex-cli 0.154 `--help` lists no event names), with JSONL as a fallback.
- `make llm-local` serves the pinned revision on 127.0.0.1; mlx-lm is a macOS-arm64-only dev dependency (osv-scanner: no issues across 121 locked packages).
- `.env.example` uses `GOOGLE_API_KEY` for Gemini (the name LangChain reads).
- `scripts/provider_live_check.py` is the reusable live smoke test.
