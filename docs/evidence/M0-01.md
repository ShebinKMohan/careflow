## 3. LiteLLM in any `pyproject.toml` makes the check exit 1

Pytest: `scripts/tests/test_check_banned_deps.py::test_adding_litellm_to_any_pyproject_fails` is parametrized over all 9 `pyproject.toml` files in the repo (root plus 8 members). 26 cases in that file cover spellings, `uv.lock`, `package.json`, `pnpm-lock.yaml`, unconstrained requirements and workspace exemptions.

Manual run with `litellm>=1.0` added to `services/api/pyproject.toml` (reverted afterwards):

```
$ uv run --no-sync python scripts/check_banned_deps.py
check_banned_deps: 1 problem(s)
  services/api/pyproject.toml: project.dependencies: banned package 'litellm' (see ADR-003)
exit=1
$ make banned-deps
make: *** [banned-deps] Error 1
$ make lint-py            # UV_LOCKED=1: uv refuses instead of installing
hint: To update the lockfile, run `uv lock`.
make: *** [lint-py] Error 1
```

**Finding and deviation.** The literal `uv run python scripts/check_banned_deps.py` re-resolves the project and installs newly declared dependencies *before* the script runs. Verifying this criterion that way started a LiteLLM download. It was stopped before anything was installed, then `uv.lock` and the pyproject were reverted, the venv re-synced (no `litellm`, `openai` or `botocore` in site-packages) and uv's cache purged. The fix: `make install` and `make check` run the check first with `uv run --no-project`, the CI `security` job runs it without syncing, and the Makefile exports `UV_LOCKED=1` (recorded in ADR-003).

## Deviations from the issue text

- `make install` uses `uv sync --locked --all-packages`: the root is a virtual workspace, so the flag makes "install every member" explicit.
- The banned-deps check runs outside the project environment and before any sync, and `UV_LOCKED=1` is exported (section 3).
- TypeScript is pinned to 6.0.3, not 7.x: typescript-eslint 8.70.1 requires `typescript <6.1`.
- Homebrew's `rustup` formula no longer ships `rustup-init`, so `bootstrap_mac.sh` uses `rustup toolchain install stable --profile minimal` when no toolchain exists.
- Added `scripts/run_with_timeout.py` and `scripts/lib.sh` (`with_timeout` uses `gtimeout`, else the Python wrapper), plus per-language Makefile targets (`install-py`, `lint-node`, ...) that the CI jobs call.
