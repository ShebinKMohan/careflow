## Deployment boundary

The owner explicitly chose frontend-only hosting for now and deferred the
backend/model hosting decision. This is a hosted **frontend preview**, not a
connected public check-in service.
The FastAPI service, Postgres, Redis, FHIR server, Qwen and Laya currently run
on the Mac. No hosted API endpoint, public tunnel, external model provider,
paid resource, or patient-device secret was configured for this release.
The companion and staff applications remain available on the local stack.

The unconfigured Vercel welcome screen explicitly identifies the preview,
does not offer a fabricated QR or token, and does not wait for nonexistent
device provisioning. Configured local installations keep their existing flow.
A hosted backend and its exact public origins are needed before enabling
public patient registration, QR handoff, model processing or nurse actions.

Source uploads exclude local environments, dependencies, infrastructure/data,
model weights, test artifacts and evidence screenshots. Git also excludes
signed welcome QR screenshots and the unrelated local `.claude/launch.json`.
