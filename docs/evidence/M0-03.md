## CI

New `contracts` job: fetches `main`, installs checksum-verified oasdiff, runs `make install` and `make contracts-check` (lint, regenerate-and-diff, breaking). The M0-02 drift step moved from the `python` job into this job.

## Deviations from the issue text

- `api_models.py` is generated with `--external-ref-mapping` (datamodel-codegen cannot write one file for a spec with external refs otherwise) and `--use-type-alias` without `--collapse-root-models`. For that, the M0-02 schemas lost their `$id` and expose each root type as `#/$defs/<Name>`; class names and imports are unchanged (ADR-010).
- Event data schema files use hyphens (`alert-raised.schema.json`); event types keep their dots.
- `POST /v1/checkin/qr/claim` needs no bearer: its single-use `qr_token` is the credential.
- Added to the contract: `TriageView.needed_facts` and `decision`, the `DecisionResult` {decision, token} response, `Task`, `WorklistItem`, `AlertChip`, a board-only `BoardEntry`, and `x-careflow-roles` per operation.
- Redocly `recommended` with two rules off (`info-license`: no licence chosen; `no-invalid-media-type-examples`: validator bug, covered by pytest).
- `bootstrap_mac.sh` also installs oasdiff; ruff's `src` now lists `packages/*/src` and `services/*/src`, so first-party imports sort consistently.
