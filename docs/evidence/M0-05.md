# Evidence: [M0-05] Stand up Docker infra and load Synthea patients into HAPI FHIR

- Linear: SHE-286. Branch `she-286-docker-infra`. Machine: MacBook Pro M3 Pro, Docker 29.8.0, Compose v5.5.1 (Docker VM 8.3 GB).
- Images, all pinned by digest: `pgvector/pgvector:0.8.6-pg17-bookworm` with pg_textsearch 1.4.0 built on top (tarball SHA-256 verified), `valkey/valkey:8.1.10`, `hapiproject/hapi:v8.12.0-1` (HAPI FHIR 8.12.0; no 8.12.1 image is published yet; ADR-012), and `eclipse-temurin:21.0.12.1_1-jre-noble` for Synthea.

## 1. `make up` brings every service to healthy in under 3 minutes; the memory budget passes

```

wait_for_http: http://localhost:8080/fhir/metadata is up after 19s
$ docker compose ps
hapi: Up 19 seconds    postgres: Up 25 seconds (healthy)    valkey: Up 25 seconds (healthy)

$ python3 scripts/check_mem_budget.py
  hapi         2560 MiB
  postgres     1024 MiB
  valkey       256 MiB
check_mem_budget: total 3.75 GiB of 6.00 GiB
```

The first `make up` also builds the Postgres image: 279 s including `apt-get` and compiling pg_textsearch; HAPI answered 21 s after starting. HAPI's image is distroless (`/bin/sh` does not exist), so `make up` polls `/fhir/metadata` (180 s limit) instead of using a container healthcheck. It reports `fhirVersion 4.0.1`, "HAPI FHIR Server 8.12.0". Peak memory during the bulk load: HAPI 2.14 GiB of 2.5 GiB, Postgres about 0.2 GiB, Valkey about 13 MiB. No OOM kill and no restart.

## Deviations from the issue text

- HAPI FHIR 8.12.0 (image v8.12.0-1) instead of 8.12.1: no 8.12.1 server image is published (ADR-012).
- HAPI gets its own `hapi` role and database (the issue did not name HAPI's DB user). Passwords come from `.env` through psql `\getenv`, and `gen_dev_env.py` now derives the connection URLs.
- Ports bind to 127.0.0.1 only; Valkey runs with `maxmemory 192mb` and `noeviction`.
- `load_fhir.py` uses 4 parallel workers for patient bundles (after the shared hospital and practitioner bundles), with retries on 409/5xx; persona appointments are booked for the seeding date (`__TODAY__`).
- Added `scripts/wait_for_http.py` (stdlib poller), and `pyright` now includes `infra/`.
